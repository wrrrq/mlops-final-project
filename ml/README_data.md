# 数据版本控制说明 (Data Versioning)

## 数据来源 (Source)
本项目的数据来源于 `ml/generate_data.py` 脚本生成的模拟医疗数据。数据包含 500 条患者特征，包括年龄 (age)、静息血压 (resting_bp) 和胆固醇 (cholesterol)，以及目标标签 (target: 1为高风险，0为低风险)。

## 数据版本变更 (v1 -> v2)
- **v1 版本**：初始生成的 500 条原始数据，包含了极小概率出现的未成年数据（如年龄低于25岁），这在真实心血管疾病统计中属于异常边缘情况。
- **v2 版本**：在 v1 的基础上进行了数据清洗（Data Cleaning），去除了年龄小于 25 岁的异常数据，使数据集分布更贴近真实的中老年患病群体。

## 版本与代码对应关系
- v1 数据版本对应 Git Tag: `dvc-v1`
- v2 数据版本对应 Git Tag: `dvc-v2`
